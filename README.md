# BeatsTimer

**运动伴侣 · 节奏音乐 + 语音报时**

BeatsTimer 是一款为运动场景设计的 Android 应用：一边播放你喜欢的节奏音乐，一边按设定的时间间隔用语音播报当前时间（如"9点5分"、"12点整"），让你在跑步、骑行、健身时不必频繁看表也能掌握时间节奏。所有语音由系统离线 TTS 合成，无需联网。

## 功能特性

- **节奏音乐播放**：从手机中选择本地音乐循环播放，边听歌边运动；未选择音乐时自动播放内置保活音轨（不可闻，仅用于后台稳定运行）
- **定时语音报时**：间隔 1–240 分钟可调（默认 5 分钟）；整点播报"X点整"、非整点播报"X点Y分"
- **报时倒计时 + 总时长**：显示距下次播报的剩余时间，以及本次报时已累计的总时长（按分钟累计）
- **暂停 / 恢复**：一键暂停倒计时、总时长累加与音乐播放；恢复时从暂停位置继续，不重新开始
- **音量智能压低**：播报瞬间自动把音乐音量压低至约 20%，播报结束自动恢复，报时语音清晰且不打断音乐
- **锁屏媒体控制**：基于 MediaSession + 媒体通知，锁屏与通知栏显示状态卡片，可直接开始 / 停止报时
- **极致后台保活**：前台服务（specialUse）+ WakeLock + 真实音频播放（防 Deep Doze 与缓存冻结）+ AlarmManager 兜底（穿透 Doze 补触发），长时间后台 / 锁屏不中断
- **运行稳定性自检**：一键检查通知权限、电池优化白名单、精确闹钟授权，并给出各厂商自启动设置指引
- **离线 TTS**：使用系统 TextToSpeech，无网络依赖
- **极简界面**：语义色板 + 卡片分层设计，支持深色模式

系统要求：Android 8.0（API 26）及以上。

## 构建与发布（GitHub Actions，无需本地 Android 环境）

### 方式一：打 tag 自动构建并发布 Release（推荐）

```bash
git tag v1.6.5
git push origin v1.6.5
```

推送 tag 后自动触发 **Build APK** 工作流：

1. 云端编译 APK，版本号自动取自 tag（`v1.6.5` → `versionName = 1.6.5`，`versionCode` 取运行序号）
2. 产物重命名为 **`BeatsTimer_v1.6.5.apk`**
3. 自动创建同名 GitHub Release 并上传该 APK（附自动生成的变更说明）
4. 同时保留 Actions Artifacts（`beatstimer-apk`，保留 30 天）

**下载安装**：仓库页面右侧 **Releases** → 选择版本 → 下载 `BeatsTimer_vX.Y.Z.apk`，传到手机安装（需允许"安装未知来源应用"）。

> 约定：版本号即 tag 名（建议 `vX.Y.Z`）；Release 资产文件名 = `BeatsTimer_<tag>.apk`。

### 方式二：手动触发（用于测试，不发布 Release）

仓库 → **Actions** 页签 → 左侧 **Build APK** → **Run workflow**。该方式仅产出 Actions Artifacts（版本号取自 `app/build.gradle.kts`），不创建 Release。

### 本地构建（可选）

安装 Android Studio 后直接打开本目录，`Build > Build APK(s)` 即可。

## App 使用说明

1. 安装并打开 BeatsTimer
2. 设定报时间隔（分钟，默认 5）
3. （可选）点击 **选择音乐** 从手机中选择本地音乐；右侧 ✕ 可清除已选音乐
4. （可选）拖动 **音量** 滑块调节音乐音量（实时生效）
5. 点击 **开始报时**：立即播报一次当前时间并开始播放音乐，倒计时与总时长开始运行；通知栏与锁屏出现媒体控制卡片
6. **暂停 / 恢复**：报时中点 **暂停**，倒计时、总时长累加与音乐同时暂停，按钮变为 **恢复**；再次点击从暂停位置继续
7. **停止报时**：结束本次报时并归零（音乐停止，按钮回到"开始报时"）
8. 点击底部 **运行稳定性设置** 查看授权状态并逐项授权
9. 彻底退出：从最近任务列表划掉 BeatsTimer，通知与锁屏卡片随之消失

> **音频协调**：音乐播放持有音频焦点；播报瞬间音乐自动压低至约 20%，播报结束自动恢复。
>
> **保活说明**：报时期间，本应用在系统看来是一个"正在播放音频的媒体应用"（你的音乐或内置保活音轨），因此不会被 Deep Doze 挂起、也不会被缓存冻结；前台服务与 AlarmManager 兜底进一步确保计时不丢失。暂停时会停止音频播放与兜底闹钟，以减少耗电。
>
> **后台稳定性提示**：部分国产手机（小米 / 华为 / OPPO / vivo 等）后台管控较激进，除在 app 内允许"通知 / 电池优化 / 精确闹钟"外，还需在系统设置中为 BeatsTimer 开启 **自启动** 并将后台管控设为 **无限制 / 允许后台运行**（具体路径见 app 内"运行稳定性设置"弹窗）。另外请勿在系统设置中对本应用执行"强行停止"。
>
> **提示**：若设备未安装中文 TTS 语音包（如部分原生系统），请到 系统设置 → 无障碍 / 语言 → 文字转语音（TTS）中安装中文语音数据。
